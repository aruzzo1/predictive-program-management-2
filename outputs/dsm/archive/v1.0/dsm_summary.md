## Orientation

**Row = source / upstream node; column = target / downstream node.** A nonzero entry (i, j) means node i feeds node j: some
activity in i must finish before an activity in j. This convention is used in every file in this folder.

## Weighting policy

| Tier | Weight | Rule |
|---|---|---|
| STRONG | 1.00 | Evidence-derived and SUPPORTED by an agentic decision. |
| MODERATE | 0.75 | Evidence-derived and PARTIALLY_SUPPORTED by an agentic decision, or (no agentic decision) stated directly by a recorded passage (EXPLICIT_PASSAGE). |
| UNRESOLVED_RETAINED | 0.50 | Evidence-derived but UNRESOLVED by an agentic decision, or (no agentic decision) assembled only from fragments (FRAGMENTARY). Retained in the experimental model. |
| SYNTHETIC_SEQUENCING | 0.25 | Purely synthetic sequencing dependency (data_classification SYNTHETIC). |
| EXCLUDED | 0.00 | Evidence-derived but NOT_SUPPORTED by an agentic decision. Kept in the registry, not in the matrix. |

Precedence: Agentic decision if one exists for the dependency, else the passage support label for DERIVED dependencies, else SYNTHETIC_SEQUENCING. The agentic decisions used come from single REAL_LLM_MODE runs:
Q01 PARTIALLY_SUPPORTED, Q04 UNRESOLVED and Q08 UNRESOLVED.

## Uncertainty treatment

UNRESOLVED does not mean there is no relationship. An UNRESOLVED dependency is retained at 0.50 rather than dropped, and
the binary DSM marks it present, because it is intentionally part of the experimental model. The weighted DSM is where
the lower confidence shows. Only an agentic NOT_SUPPORTED decision would give 0.00 (EXCLUDED); none exists.

- DEP-028 A325 -> A405 (Q04): weight 0.50, shown in cell D5->D6.
- DEP-037 A430 -> A510 (Q08): weight 0.50, intra-node (D7), so it is kept in the registry, not shown in the matrix.

## Feedback and coupling

- **Rework feedback.** The approved FEEDBACK_REWORK dependency A425 -> A410 lies inside Flight-Test Execution, so it
  appears as the diagonal entry **D6->D6**. It is the only allowed exception to the zero diagonal. The baseline IMS
  stays acyclic; the loop exists only in the dependency registry and the DSM.
- **Coupled blocks** (strongly connected components of the binary DSM): {D2, D3}; {D6}; {D7, D8}. {D2, D3} (design <-> weight) and
  {D7, D8} (test maturity <-> production commitment) are created by aggregating approved activity links. The activity
  network itself has no cycle. {D6} is the rework self-loop.

## Limitations

- This is an illustrative capstone model built on a synthetic schedule, not a historical F-35 DSM.
- The weights are ordinal tiers. Max-aggregation hides how many links support a cell.
- Agentic decisions take precedence over passage labels. This puts Q04 (UNRESOLVED at 69.5, despite explicit passages)
  below untested EXPLICIT_PASSAGE concepts such as Q07 D3->D8 (0.75).
- The Q08 concept link A430 -> A510 is intra-node (both in D7), so its UNRESOLVED weight does not appear in the matrix.
  D7->D8 carries only synthetic sequencing (0.25).
- There is no flight-test -> software-maturity feedback (D6 -> D4), because the frozen registry has no such dependency.
  The corrective activity A420 is assigned to D6.
- Not built: WTM, propagation simulation, intervention simulation.
