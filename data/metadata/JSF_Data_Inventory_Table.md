## Method

Links were cross-referenced against the project reference document `Data_Source_Search_JSF.docx` and authoritative public sources: gao.gov, dote.osd.mil, lockheedmartin.com, govinfo.gov, anao.gov.au, rand.org, asbca.mil and arc.aiaa.org. A link was accepted only after it resolved (live, or through an Internet Archive capture where the live site blocks automated requests) and the document's identity matched the local file. Identity was checked by SHA-256 hash, or by page count plus matching text for browser re-saved copies. Tracking parameters (`?utm_source=chatgpt.com`) were removed, and malformed docx links were corrected. Content topics were checked against each document's own text.
